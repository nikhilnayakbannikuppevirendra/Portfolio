## Development Setup

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/Portfolio.git
cd Portfolio


1. **Place `index.html` in the Root Directory**  
   Ensure your main entry file `index.html` is located in the root of the repository (not inside any subfolder like `templates/`).

2. **Go to Repository Settings**  
   Open your GitHub repository and navigate to the **Settings** tab.

3. **Navigate to Pages Section**  
   In the left sidebar, click on **Pages**.

4. **Configure Deployment Source**  
   - Source: **Deploy from branch**  
   - Branch: **main**  
   - Folder: **/ (root)**  

5. **Access Your Deployed Website**  
   Once configured, GitHub will deploy your site.  
   Visit the **GitHub Pages** section or open your live link to view the deployed portfolio.
